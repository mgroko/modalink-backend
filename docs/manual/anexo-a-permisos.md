# Anexo A. Permisos por rol

## A.1. Roles globales

| Acción | Usuario | Administrador |
|---|---|---|
| Crear cuenta e iniciar sesión | Sí | Sí |
| Crear y administrar perfiles propios | Sí | No |
| Buscar perfiles, proyectos y oportunidades | Sí | No |
| Conectar, publicar y enviar mensajes | Sí | No |
| Crear proyectos y participar en ellos | Sí | No |
| Firmar contratos y calificar equipos | Sí | No |
| Ver el Panel de Administración | No | Sí |
| Gestionar usuarios | No | Sí |
| Gestionar catálogos (características, habilidades, unidades, tipos de contrato) | No | Sí |
| Configurar tareas automáticas | No | Sí |
| Gestionar reportes de perfil y de publicaciones | No | Sí |
| Consultar y exportar la auditoría | No | Sí |

## A.2. Roles dentro de un proyecto

| Acción | Director | Miembro |
|---|---|---|
| Ver el proyecto, la planificación y los miembros | Sí | Sí |
| Editar el proyecto | Sí | No |
| Publicar el proyecto | Sí | No |
| Confirmar el proyecto | Sí | No |
| Finalizar el proyecto | Sí | No |
| Cancelar el proyecto | Sí | No |
| Crear, editar, cancelar y eliminar actividades | Sí | No |
| Asignar y desasignar integrantes | Sí | No |
| Crear y modificar requerimientos | Sí | No |
| Gestionar postulaciones | Sí | No |
| Invitar a perfiles al proyecto o a una actividad | Sí | No |
| Eliminar invitaciones enviadas | Sí | No |
| Eliminar integrantes | Sí | No |
| Gestionar reemplazos | Sí | No |
| Ver el historial de miembros | Sí | No |
| Usar el chat grupal | Sí | Sí |
| Firmar o rechazar sus contratos | Sí | Sí |
| Generar, modificar y eliminar contratos | Sí | No |
| Calificar al equipo | Sí | Sí |
| Darse de baja del proyecto | Sí, si queda otro Director | Sí |
| Asociar publicaciones al proyecto | Sí | Sí |

## A.3. Permisos de administración

| Permiso funcional | Qué habilita |
|---|---|
| Ver usuarios | Consultar usuarios, su detalle y sus perfiles; ver el Dashboard. |
| Habilitar usuarios | Volver a habilitar una cuenta deshabilitada. |
| Deshabilitar usuarios | Suspender una cuenta con motivo y duración. |
| Ver características técnicas | Consultar el catálogo de características. |
| Crear características técnicas | Alta de características y de valores de catálogo. |
| Modificar características técnicas | Edición de características y de valores. |
| Eliminar características técnicas | Baja de características y de valores. |
| Ver habilidades | Consultar el catálogo de habilidades. |
| Crear habilidades | Alta de habilidades. |
| Modificar habilidades | Edición de habilidades. |
| Eliminar habilidades | Baja de habilidades. |
| Ver tipos de contrato | Consultar el catálogo de tipos de contrato. |
| Crear tipos de contrato | Alta de tipos y plantillas. |
| Modificar tipos de contrato | Edición y cambio de estado de tipos. |
| Eliminar tipos de contrato | Baja de tipos sin contratos asociados. |
| Administrar configuración | Acceder a schedulers, reparación de cronogramas y colaboraciones históricas. |

> Los permisos se validan en el servidor. Si una acción no está habilitada para tu rol, la interfaz puede ocultarla o deshabilitarla, y el servidor la rechaza aunque se intente.

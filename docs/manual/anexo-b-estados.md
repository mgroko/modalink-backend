# Anexo B. Estados y su significado

## B.1. Usuario

| Estado | Significado | Qué puede hacer el usuario |
|---|---|---|
| **Activo** | La cuenta está habilitada. | Iniciar sesión y usar la plataforma. |
| **Deshabilitado** | Un administrador suspendió la cuenta con un motivo y, opcionalmente, un plazo. | No puede iniciar sesión hasta ser habilitado o hasta que venza la suspensión temporal. |
| **Pendiente de baja** | El usuario solicitó la baja y está dentro del plazo de recuperación. | No puede iniciar sesión; puede reactivar la cuenta desde el aviso de login. |
| **Baja** | El plazo venció o la cuenta fue dada de baja. | No puede iniciar sesión. |

## B.2. Perfil

| Estado | Significado | Visibilidad |
|---|---|---|
| **Activo** | El perfil está habilitado. | Visible para la comunidad. |
| **Deshabilitado** | El perfil fue deshabilitado. | No visible para la comunidad; el dueño puede verlo y editarlo. |
| **Pendiente de baja** | El dueño solicitó la baja del perfil y está dentro del plazo. | No visible para la comunidad; puede reactivarse. |
| **Baja** | El plazo venció o el perfil fue dado de baja. | No visible; no se puede editar ni reactivar. |

## B.3. Proyecto

| Estado | Significado | Acciones principales |
|---|---|---|
| **Borrador** | El proyecto se está preparando. Solo lo ve el equipo. | Editar, completar información, publicar. |
| **Publicado** | El proyecto es visible según su privacidad y acepta postulaciones e invitaciones. | Editar, confirmar, cancelar, invitar, gestionar postulaciones. |
| **Confirmado** | Se fijó la fecha de inicio y las actividades están agendadas. | Editar con restricciones, finalizar, cancelar, asignar, gestionar reemplazos. |
| **Finalizado** | El proyecto cerró y se calificó al equipo. | Consultar, ver historial y contratos. |
| **Cancelado** | El proyecto se canceló con un motivo. | Consultar; no se puede editar ni reactivar. |

## B.4. Actividad

| Estado | Significado | Acciones principales |
|---|---|---|
| **Pendiente** | La actividad está planificada y todavía no comenzó. | Editar, asignar, iniciar, cancelar. |
| **En curso** | La actividad comenzó. | Finalizar o cancelar. |
| **Finalizada** | La actividad terminó. | Consultar. |
| **Cancelada** | La actividad se canceló. | Consultar; no se puede modificar. |

## B.5. Postulación

| Estado | Significado |
|---|---|
| **Pendiente** | El Director todavía no respondió. Se puede retirar. |
| **Aceptada** | El postulante pasó a ser miembro o quedó asignado a la actividad. |
| **Rechazada** | El Director rechazó la postulación o el cupo se cubrió automáticamente. |

## B.6. Invitación

| Estado | Significado |
|---|---|
| **Pendiente** | El destinatario todavía no respondió. El Director puede eliminarla. |
| **Aceptada** | El destinatario pasó a ser miembro o quedó asignado a la actividad. |
| **Rechazada** | El destinatario rechazó la invitación. No se creó membresía ni asignación. |

## B.7. Contrato y firma

### Contrato

| Estado | Significado |
|---|---|
| **Borrador** | El contrato se está preparando; no se emitió. |
| **Pendiente de firma** | El contrato fue emitido y espera firmas. |
| **Activo** | Todas las partes activas firmaron. |
| **Rechazado por las partes** | Alguien rechazó el contrato. |
| **Cancelado** | El contrato fue cancelado. |
| **Eliminado** | Se dio de baja y se conserva como historial. |

### Firma de una parte

| Estado | Significado |
|---|---|
| **Pendiente** | La parte todavía no firmó. |
| **Firmado** | La parte firmó. |
| **Rechazado** | La parte rechazó el contrato e indicó un motivo. |
| **Cancelada** | La firma pendiente se canceló porque el contrato se rechazó o se eliminó. |
| **Invalidada** | La firma quedó invalidada por una modificación del contrato. |

## B.8. Publicación y reportes

| Estado | Significado |
|---|---|
| **Publicación activa** | Visible en el portfolio y en el feed. |
| **Publicación oculta** | Ocultada por la administración; solo el dueño la ve en **Publicaciones ocultas**. |
| **Reporte pendiente** | Espera revisión de la administración. |
| **Reporte resuelto** | La administración lo revisó y tomó una decisión. |
| **Reporte descartado** | La administración lo revisó y no encontró motivos para actuar. |

## B.9. Colaboración automática

| Estado | Significado |
|---|---|
| **Pendiente** | Espera la respuesta de uno o ambos perfiles. |
| **Confirmada** | Ambos perfiles confirmaron; la colaboración está activa. |
| **Rechazada** | Uno de los perfiles rechazó la propuesta. |
| **Cancelada** | Una publicación o la imagen dejó de estar disponible. |
| **Disuelta** | Un perfil se quitó como colaborador. |

## B.10. Reemplazo

| Estado | Significado |
|---|---|
| **Pendiente de confirmación del Director** | El sistema detectó la vacante y propone candidatos. |
| **Invitaciones enviadas** | Se enviaron invitaciones a los candidatos. |
| **Pendiente de aprobación** | Un candidato aceptó y espera la aprobación del Director. |
| **Cubierto** | La vacante se cubrió. |
| **Sin candidatos** | No se encontraron candidatos disponibles. |
| **Cancelado** | El proceso se canceló. |
| **Expirado** | El proceso venció. |

### Candidato de reemplazo

| Estado | Significado |
|---|---|
| **Propuesto** | El sistema lo propuso, todavía no fue invitado. |
| **Invitado** | Recibió la invitación y espera responder. |
| **Aceptado pendiente de aprobación** | Aceptó y espera la decisión del Director. |
| **Aprobado** | Se incorporó al proyecto. |
| **Rechazado** | Rechazó la invitación o el Director lo rechazó. |
| **Expirado** | La invitación venció. |
| **Cancelado** | El proceso o la candidatura se canceló. |

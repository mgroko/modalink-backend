# 2. Conceptos básicos

## 2.1. Usuario y perfil

ModaLink separa la **cuenta** de la **identidad profesional**.

- **Usuario:** es la cuenta con la que ingresás. Tiene tus datos personales (nombre, apellido, DNI, fecha de nacimiento, género, correo y ubicación), una sola contraseña y un rol global. Un usuario puede tener **varios perfiles**.
- **Perfil:** es la identidad profesional con la que actuás en la plataforma. Tiene una profesión, un nombre artístico, una biografía, características técnicas, habilidades, foto y polaroids. Cada perfil pertenece a un usuario y tiene su propio estado.

Ejemplo: una misma persona puede tener un perfil de **Fotógrafo** y otro de **Productor de Moda**. Los proyectos, postulaciones, conexiones, mensajes y publicaciones siempre se generan **desde el perfil activo**, no desde el usuario.

### Perfil activo

Es el perfil seleccionado en ese momento. Se muestra en la barra superior y en la barra lateral. Muchas pantallas solo funcionan con un perfil activo; si no hay ninguno, el sistema te lleva al panel de usuario para que elijas o crees uno.

Para cambiar de perfil activo usá el menú del perfil, arriba a la derecha, y elegí **Cambiar perfil activo**. Solo se pueden activar perfiles en estado **Activo**.

## 2.2. Roles globales

| Rol | Alcance | Qué puede hacer |
|---|---|---|
| **Usuario** | Toda la plataforma | Crear y administrar sus perfiles, buscar, conectar, publicar, participar en proyectos, contratar, firmar, chatear y calificar. |
| **Administrador** | Panel de Administración | Gestionar usuarios, catálogos, reportes, auditoría y configuración del sistema. No opera con perfiles profesionales ni participa en proyectos. |

El rol global se asigna al crear la cuenta. Las cuentas nuevas se crean como **Usuario**.

## 2.3. Roles dentro de un proyecto

Cada proyecto tiene integrantes con uno de estos roles:

| Rol | Qué puede hacer |
|---|---|
| **Director de proyecto** | Crear y modificar el proyecto, publicarlo, confirmarlo, finalizarlo o cancelarlo; crear y editar actividades; asignar integrantes; invitar; gestionar postulaciones; eliminar integrantes; generar y administrar contratos; aprobar reemplazos. |
| **Miembro de proyecto** | Ver el proyecto y su planificación, participar del chat grupal, firmar o rechazar sus contratos, calificar al equipo cuando el proyecto finaliza y darse de baja. |

Un proyecto puede tener más de un Director. El sistema impide que se elimine o se dé de baja el último Director activo.

### Permisos y validaciones

Además del rol, el sistema valida **permisos** para cada acción de administración y de proyecto. Si intentás una acción para la que no tenés permiso, la interfaz la oculta o la muestra deshabilitada, y el servidor la rechaza aunque se intente igual.

En los capítulos de proyectos se indica qué rol puede hacer cada cosa. El detalle completo está en el **Anexo A**.

## 2.4. Glosario

| Término | Significado |
|---|---|
| **Proyecto** | Producción creativa o de moda (campaña, sesión, desfile, audiovisual) que se organiza en la plataforma. Tiene nombre, descripción, privacidad, fechas, ubicación, objetivos, moodboard, requerimientos, actividades e integrantes. |
| **Actividad** | Tarea concreta dentro de la planificación de un proyecto. Tiene duración, dependencias, ubicación, requerimientos de personal, responsables y estado. |
| **Requerimiento** | Necesidad de personal de un proyecto. Puede ser **general** (para todo el proyecto) o **por actividad**. Indica cantidad de personas, profesión, características técnicas y habilidades. |
| **Postulación** | Solicitud de un perfil para cubrir un requerimiento. Queda en estado **Pendiente** hasta que un Director la acepta o la rechaza. |
| **Invitación** | Propuesta directa de un Director para sumar un perfil a un proyecto o a una actividad. También puede ser una invitación de reemplazo. |
| **Oportunidad** | Requerimiento abierto al que te podés postular. Se busca desde **Buscar** o desde **Inicio**. |
| **Agenda** | Disponibilidad semanal de un perfil. Se compone de la jornada laboral, el margen entre actividades y los bloqueos. |
| **Jornada laboral** | Franja horaria en la que un perfil trabaja cada día. Puede ser corrida o partida (mañana y tarde). |
| **Margen entre actividades** | Tiempo mínimo que el sistema deja entre el fin de una actividad y el inicio de la siguiente para un mismo perfil. |
| **Bloqueo** | Período en el que un perfil no está disponible (por ejemplo, vacaciones o un compromiso personal). |
| **Conexión** | Vínculo activo entre dos perfiles. Habilita el chat privado y permite ver proyectos privados de los contactos. |
| **Publicación** | Contenido que un perfil comparte en su portfolio, con imágenes, descripción, ubicación y, opcionalmente, un proyecto asociado. |
| **Colaboración** | Vínculo entre un perfil y una publicación. Un colaborador aparece etiquetado en la publicación. |
| **Polaroid** | Foto profesional del perfil, clasificada por tipo de plano, que se muestra en una galería. |
| **Moodboard** | Tablero de imágenes de referencia de un proyecto. |
| **Contrato** | Acuerdo generado a partir de una plantilla, con partes, texto y firmas. Puede estar en borrador, pendiente de firma, activo, rechazado, cancelado o eliminado. |
| **Calificación / reseña** | Valoración de 1 a 5 estrellas con un texto obligatorio, que se registra al finalizar un proyecto. |
| **Notificación** | Aviso dentro de la plataforma sobre una acción que te involucra. |
| **Cronograma** | Cálculo automático de fechas de inicio y fin de las actividades, dependencias, ruta crítica y holguras. |
| **Ruta crítica** | Secuencia de actividades que determina la duración mínima del proyecto. |
| **Colaboración automática** | Propuesta de vinculación entre perfiles o publicaciones que el sistema detecta a partir de coincidencias. Requiere confirmación de las partes. |
| **Reemplazo** | Proceso que se activa cuando un integrante se da de baja o es eliminado de un proyecto confirmado, para cubrir la vacante con nuevos candidatos. |

## 2.5. Cómo se relacionan

- Un **usuario** tiene uno o más **perfiles** y un **perfil activo**.
- Los **perfiles** se conectan entre sí mediante **conexiones**.
- Los **proyectos** tienen **integrantes** con rol **Director** o **Miembro**.
- Los **requerimientos** se cubren con **postulaciones** aceptadas o **invitaciones** aceptadas.
- Las **actividades** se asignan a **miembros** y se agendan según la **disponibilidad** de cada perfil.
- Al finalizar, los integrantes se **califican** y las calificaciones quedan en los perfiles.
- Los **contratos** vinculan al Director con las partes y se firman desde la plataforma.

## 2.6. Estados

Las pantallas y los flujos cambian según el estado de la cuenta, del perfil, del proyecto, de la actividad, de la postulación, de la invitación y del contrato. El significado de cada estado, y qué podés hacer en cada uno, está en el **Anexo B**.
